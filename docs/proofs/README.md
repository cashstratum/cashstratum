# Proofs

Evidence for the claims made in the README, mirrored here so it is verifiable at the source and
survives the website going down. The presented version — charts, explorer links, narrative — lives
at [cashstratum.com](https://cashstratum.com).

## What belongs here

- **Block proofs** — height, hash, timestamp, coinbase tag, explorer link, and the pool log lines
  around the find.
- **Hashrate records** — what the pool was actually running when a block was found. The most
  recent mainnet block was found with under 400 TH/s; the log is the point, not the number.
- **Benchmarks** — the command, the hardware, the node version, and the raw output. A benchmark
  nobody can re-run is marketing, not evidence.
- **Compatibility runs** — miner/firmware combinations tested, with the share logs.

## Rules

- Every file states how it was produced. No summaries without the underlying log.
- Logs are scrubbed of hostnames, IPs and anything identifying an individual miner before they
  land here.
- Nothing is edited after publication. A correction is a new file that references the old one.

Contents land with the `v1.0.0` release.
